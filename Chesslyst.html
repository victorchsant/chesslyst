Interface do Chesslyst

A interface precisa do servidor local para analisar as partidas.
1. No Windows, dê dois cliques em iniciar.pyw (nesta mesma pasta, sem janela de terminal). No Linux/Mac, rode python iniciar.py. Ele prepara tudo, inicia o servidor e abre a interface.
2. Se o servidor já estiver rodando, use o botão abaixo.

Requer Python 3.10+. Na primeira vez ele baixa o python-chess (precisa de internet).
