Código-fonte

Este programa é software livre, sem garantia. As engines (Stockfish, Lc0) e as redes Maia não fazem parte do projeto: são baixadas da fonte oficial e continuam sob a licença original de cada uma. Dados de teoria e finais vêm da API aberta do Lichess; só a posição (FEN) é enviada.

🖥 Engines e modelo de jogadores

Baixar engines (fonte oficial) Este projeto não inclui engines. O download é feito por você, direto do GitHub oficial de cada projeto, e a engine continua sob a licença original (GPL-3.0).

Você também pode cadastrar abaixo qualquer engine UCI que já tenha (Stockfish, Lc0, Komodo, Berserk…). A referência calcula o índice; as demais aparecem ao lado e geram o aviso de divergência. Vale para a próxima análise iniciada.
